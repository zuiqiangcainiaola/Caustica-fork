## 3. 验证记录

- Minecraft 26.2，Fabric Loader 0.19.3，Fabric API 0.156.0+26.2，Windows x64，RTX 4060 Laptop GPU。Voxy 组安装 0.2.19-beta 和 Sodium 0.9.1，基线组移除两者。测试驱动只安装在隔离实例。
- 存档使用 OSHACRA ISLAND 的副本。游戏升级了旧版文件，旧的 Terralith 世界生成配置无法在该 26.2 环境解析，因此只在副本替换生成器定义；保留原种子、已生成区块和原 Voxy 数据库。对照取自同一副本，Voxy 采集关闭。
- 原版视距 3 区块，固定视点 `(-27760.5, 115, 36435.5)`，朝东，俯角 9°。向南横移 20 格并转头，跨越区块边界后到石砖墙后方，再回到起点。记录打开视野、移动、遮挡和恢复画面。截图路径以 `build/voxy-acceptance` 为根。
- `gradlew.bat build --offline` 通过，75 项 JUnit 全部通过。新增 4 项覆盖空段、封闭段、合并面、几何绕序、负坐标相邻段和颜色边界。35 项生产 Slang 视差计算检查通过。安装包内含已校验的 SPIR-V、既有原生库与 NightConfig；Voxy 和 Sodium 只由实例安装。
- 天气脚本仍报告 60 项失败，水体脚本仍报告 13 项失败，与上一轮记录数一致，涉及旧版本号等既有断言。
- 最终 JAR 在两组均进入世界并启用 RT。安装组能辨认原版视距外的高楼、树林和热气球，移至实心墙后被遮挡，返回原视点重新可见。无 Voxy 组只保留相同近景，启动日志中 Voxy 类查找错误为零。两组固定视点见 `final-with-voxy/final-open.png` 和 `final-without-voxy/final-open.png`。
- DLSS-RR 路径以 427×240 追踪并重建至 854×480。检查 60 个连续客户端刻的横移转向采样，沿该路线未见明显天空裂缝、双层轮廓闪烁或墙面穿透。动图为 `movement.webp`，原始帧为 `final-with-voxy/sweep-*.png`。
- 原生 854×480、1 spp 时可见采样噪点。近距离拍摄存档原有土坡（视点 `-27756.5, 64.2, 36442.5`），土坡遮住后方景物，抬高镜头 21 格后恢复视野。进入无已记录远景的下界后未见主世界轮廓；Voxy 切换了世界引擎并在退出时正常关闭。截图见 `voxy-native/08-slope.png`、`09-over-slope.png` 和 `10-dimension.png`。
