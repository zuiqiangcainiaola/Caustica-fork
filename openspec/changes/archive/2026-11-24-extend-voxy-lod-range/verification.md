# OSHACRA ISLAND 实机验收

第一阶段已经能把已驻留的 Voxy 地形映在近处水面上，也能用它挡住直射太阳光。第二阶段扩大可驻留的范围，按水平距离选择 LOD。在两个新增范围机位，地标随着视距设置消失、出现，倒影与投影也随之改变。

## 实例和对照条件

- Minecraft 26.2，Fabric Loader 0.19.3，Fabric API 0.156.0+26.2，Windows，RTX 4060 Laptop GPU。有 Voxy 的实例安装 Voxy 0.2.19-beta 和 Sodium 0.9.1。无 Voxy 的实例同时移除了这两个模组。
- 使用 OSHACRA ISLAND 的独立副本，包括原存档已有的 Voxy 数据。沿用第一阶段为 26.2 升级的测试副本，其中旧版 Terralith 生成器已替换，原种子、既有区块和 Voxy 数据库保留。Voxy 采集关闭。仅在测试副本内放置白色混凝土受光面，水面使用地图已有的水。
- 原版有效视距 3 区块，旧上限为 `(3 + 16) × 16 = 304` 格。相机 FOV 70°，观察者模式，晴天，时间和天气冻结，关闭水波与平面云，曝光手动 EV 0，4 spp，最多 4 次反弹。DLSS-RR 将 427×240 重建至 854×480。每次改变设置或机位后等待地形及图像稳定。
- 所有机位瞄准同一高楼，地标参考点 `(-27656, 152, 36316)`。下列距离从玩家到地标计算，水平距离用于判定视距，另列三维距离便于复核。坐标均可直接用于 `/tp @s x y z yaw pitch`。
- 测试驱动在真实客户端写入 Voxy 设置界面应用后的同一配置字段，由 Caustica 正常的渲染循环读取；截图来自游戏主渲染目标。手动复现可直接在 Voxy 界面应用下列区块数。测试驱动单独安装在测试实例中。

## 旧范围基线

**水面倒影。** 玩家 `(-27832.5, 66, 36504.5)`，朝向 −136.89°，俯角先 4° 后 39°，时间 6000。玩家距高楼水平 **258.23 格**，三维 272.18 格。有 Voxy 组设 48 区块，第一阶段仍受 19 区块上限约束。打开视野时能在河面上辨认楼体与倒影。低头后楼顶和楼体出画，画面上部的水中仍可辨认倒置轮廓。移除 Voxy 后，两张图中的目标均消失。旧 JAR 的远景使用 L1，分段边缘用有记录的 L0 数据衔接。[有无 Voxy 原图对照](evidence/baseline-water.png)

**太阳阴影。** 玩家 `(-27856.5, 153, 36294.5)`，朝向 −90°，俯角 89°，时间 0，太阳高度约 10.7°。水平和三维距离均约 **201.65 格**。近景接收面用 `/fill -27877 121 36263 -27835 121 36325 minecraft:white_concrete` 放置，顶面在 Y=122。无 Voxy 时地面中央与右侧均受光。第一阶段装入 Voxy、视距设 48 后，中央出现宽条阴影，右侧仍受光。[有无 Voxy 原图对照](evidence/baseline-sun.png)

在扩距测试后，用最终 JAR 回到这两台机位，重新采集有无 Voxy 的画面。倒影、离屏倒影和太阳阴影均保留。最终 JAR 旧水面机位选用 L2，旧阴影机位选用 L1。[第一阶段与第二阶段同机位复测](evidence/baseline-retest.png)

## 新增范围验收

**水面倒影。** 玩家 `(-27708.5, 66, 36744.5)`，朝向 −173.07°，俯角 4° 和 39°，时间 6000。高楼水平距离 **431.70 格**，三维 440.19 格。Voxy 设 20 区块时有效半径为 320 格，目标没有驻留，较近的岸边楼房仍可见。原地改为 48 区块后半径增至 768 格，目标以 **L3，8 格体素** 驻留，较近楼房左边出现绿白相间的高楼。低头后，高楼本体出画，倒影仍在同一横向位置；保持俯角调回 20，倒影又消失。无 Voxy 时只保留近海和近景。[三组全幅原图](evidence/extended-water.png) · [低头后三组相同像素区域放大](evidence/reflection-detail.png)

**太阳阴影。** 玩家 `(-28056.5, 113, 36272.5)`，朝向 −90°，俯角 89°，时间 0。高楼水平距离 **402.86 格**，三维 404.74 格。用 `/fill -28077 81 36241 -28035 81 36303 minecraft:white_concrete` 放置近景地面，顶面在 Y=82。无 Voxy 与 20 区块两组的地面中央同样受光。原地改为 48 区块后，高楼以 **L2，4 格体素** 驻留，阴影覆盖地面中央，两侧仍受光。LOD 按 64 格瓦片中心选取，本机位到目标瓦片中心约 380 格。[三组全幅原图](evidence/extended-sun.png)

**核对遮挡物与受光点。** 在最终 JAR 的稳定帧，用相机的平水面反射方向或客户端当时的太阳方向，从近景沿线查询已驻留且未被近景取代的 Voxy 体素。下面给出 CPU 侧遇到的首个占用体素，与同机位的画面对照。射线采样没有读取 GPU 的逐像素命中缓冲。

## 移动交接与独立启动

Voxy 设 64 区块，原版仍为 3。保持 X=−27680.5、Y=122，沿 Z 轴向同一高楼移动。在 Z=37218.5、36910.5、36683.4、36460.5 时，目标水平距离依次约为 903、595、368、147 格，实机读取的驻留层级依次为 L4、L3、L2、L1。跨 L3/L2 时连续前移并转向，保留了 18 张采样。建筑在切换时会改变细部，采样中未见明显天空裂缝、重叠闪烁或穿透。已有数据的外边缘在空白背景前可见，远水沿用简化颜色。本存档实际核对到约 903 格，菜单上限按官方设置换算为 32768 格，单测覆盖该半径的瓦片选择与裁切。[LOD 交界动图](evidence/edge.webp)

在 `(-27760.5, 115, 36435.5)` 朝东、俯角 9° 横移至 Z=36455.5，再回到原点。近处石砖墙挡住远景，移回后街区重现。移除 Voxy 和 Sodium 后，最终 JAR 仍能进入同一世界，近景水、地面和建筑由 Caustica 的 Vulkan 光追正常绘制。[近景墙体遮挡动图](evidence/wall.webp)

## 构建与文件

- 最终可安装文件为 `build/libs/caustica-0.5.jar`，保留的第一阶段文件为 `build/voxy-phase2/phase1-caustica-0.5.jar`。两个安装组合实测时均从最终文件复制。单张原始截图保存在 `build/voxy-phase2/{old-on,old-off,release-on,release-off}/screenshots/`。
- Gradle 构建成功，79 项 JUnit 全通过，Slang 行为检查 35 项通过，着色器通过 SPIR-V 校验。另行运行的天气体积旧脚本报 60 项、水与玻璃旧脚本报 13 项，失败断言与第一阶段的记录逐项一致。
