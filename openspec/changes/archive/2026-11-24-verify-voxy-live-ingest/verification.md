# 探索采集、改建与重进的实机记录

第三阶段 JAR 已通过本次场景。首次探索的地形和双塔进入 Voxy 记录，拆掉黄塔后 Caustica 在同次进档中显示单塔。把玩家留在原观察点，退出游戏后启动新的客户端进程，仍可由 Voxy 恢复红塔。此次交付沿用原 JAR，产品源码、缓存策略和 LOD 均沿用第三阶段。[三张同机位实机截图](evidence/towers.png)

## 存档、塔和观察点

- 新建超平坦创造世界，种子 `421904`，关闭结构生成，晴天，时间固定为 `6000`。Minecraft 26.2，Fabric Loader 0.19.3，Fabric API 0.156.0+26.2，Voxy 0.2.19-beta，Sodium 0.9.1，RTX 4060 Laptop GPU。Caustica Vulkan 光追、手动曝光 EV 0、4 spp、DLSS-RR，输出 854×480，FOV 70°。
- 红塔用 `/fill 1026 -60 1030 1038 35 1042 minecraft:red_concrete`，黄塔用 `/fill 1058 -60 1030 1070 27 1042 minecraft:yellow_concrete`。塔身均宽 13 格，中心相隔 32 格。用 `/fill 1058 -60 1030 1070 27 1042 minecraft:air` 拆黄塔。
- 观察点 `/tp @s 1048.5 3 1272.5 180 0`，朝北平视。有效原版视距 **3 区块**，Voxy **48 区块**。从玩家到两个塔身中心的水平距离均约 **237 格**。两塔高度 Y=12 处属于同一块 64³ 远景瓦片，三张截图的驻留层级均为 **L2，4 格体素**。原版均已卸载两个采样区块，没有近景覆盖这两个位置。
- 测试驱动通过游戏的正常建档入口创建世界。起步时将角色定位到观察区，此后从观察点飞到 `(1048.5, 3, 1039.5)`、建塔或拆塔、再沿原路飞回。飞行走本地创造玩家的正常移动包。采集开关写入实例的 Voxy 配置后启动。测试驱动只读取 Voxy 和 Caustica 状态、记录事件和拍照，采集与几何发布由模组完成。

## 首次采集

首次到访前，主存档两个塔位的 L0 塔身与地基层都没有可读记录，原版目标区块也未加载。同种子的第二个全新存档额外枚举了 RocksDB 中的实际分段键，确认进入前两个塔位在 L0、L2 均无已保存页；建塔并飞离后，两处的 L0、L2 页均存在。这样可以区分存储中的页与引擎临时返回的空气。

主存档中，黄塔建成后约 6.31 秒，Voxy 的 L0、L2 都读到红色与黄色混凝土，当时原版目标区块仍已加载。约 0.40 秒后收到两个采样区块的卸载事件。抵达观察点时，两塔已写入 Voxy，远景瓦片仍在准备。抵达后 **14.11 秒**采到已驻留的 L2 几何，**14.21 秒**的固定机位截图首次同时出现红、黄两塔。帧序列按约 1 秒间隔保存。

## 同次进档拆塔与完全重启

以下用发送拆除黄塔的游戏指令为零点。Voxy 状态约每 0.25 秒采样，原版卸载通过客户端区块事件记录。时间表示本次运行第一次观察到该状态的时刻。

| 拆塔后 | 实际观察 |
| ---: | --- |
| 0.29 秒 | 黄塔位置的 L0 和 L2 均变为空气；同一高度的红塔仍为红色混凝土。两个原版区块仍在客户端。 |
| 5.69 秒 | 两个采样区块发生原版卸载。这个场景中 Voxy 数据更新先于卸载。 |
| 10.80 秒 | 回程接近观察点，采到 L2 远景几何已驻留，两塔位置均由远景负责。 |
| 11.60 秒 | 玩家返回固定观察点。 |
| 11.70 秒 | 该机位第一张截图已只剩红塔，其后约 44 秒的对照中黄塔没有重新出现。 |

正常退出，日志确认所有维度完成保存、Voxy 实例关闭。以新的 JVM 启动同一存档，玩家直接恢复在观察点，未前往塔区。运行时读到两处已有的磁盘分段键，L2 中红塔位置为红色混凝土、原黄塔位置为空气。进入世界后约 **5.65 秒**采到已驻留的 L2 几何，固定机位重拍仍是单塔。朝向记录中的 −180° 与 180° 相同。[原始事件节选](evidence/events.txt)

## 关闭采集的独立副本

在完全退出后复制存档，设置 `ingest_enabled=false`，保留 Voxy 显示和 Caustica 光追。副本直接从旧记录显示同一座红塔。随后飞到此前未经过的 `(1320, -62, 1288)` 并返回。目标距原观察点约 272 格，处于 Voxy 范围内。

出发前、在场时、离开后，存储均没有该目标的 L0、L2 页。在场时原版区块已加载，该坐标读到泥土；离开后原版卸载，该位置也没有 Voxy 远景几何。三次枚举的全库页数均为 L0 600 页、L2 40 页。返回后原有红塔依旧可见。[已有地标与新区域对照](evidence/ingest-off.png)

## OSHACRA ISLAND 东岸回归

沿用第三阶段升级的独立存档副本，关闭采集，时间 6000，原版视距 3，Voxy 视距 48。固定机位 `(-27234.5, 126, 36316.5)`，朝向 90°、俯角 13°。窄水线 `(-27504, 62, 36316)` 的 L1 记录仍为水，L2 为石头。固定机位实际驻留 L2，表面高 Y=64；靠近至 `(-27342.5, 100, 36316.5)` 时实际驻留 L1，水面高 Y=62.8889。[第三阶段与本次同机位画面](evidence/coast.png)

复走第三阶段的南北往返路线，从 `(-27400.5, 94, 36548.5)` 到 `(-27400.5, 94, 36338.5)` 再原路返回，共 217 帧，约 32 秒。动图沿用第三阶段的跟踪水块 `(-27413, 62, 36316)`，展示 L2、L1、近景及返回时的细分段交接。与第三阶段比较，复拍中未见新增的明显裂缝、闪烁或接管后残留的旧轮廓。窄水线的粗层形状继续按原记录显示。[沿岸往返实机动图](evidence/shoreline.webp)
