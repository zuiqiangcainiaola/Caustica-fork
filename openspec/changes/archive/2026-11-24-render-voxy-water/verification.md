# 第三阶段实机验收

## 同一片水的三组画面

使用 OSHACRA ISLAND 东岸同一片天然海水。观测水块为 `(-27413, 62, 36316)`，距固定机位水平约 179 格。原版视距 3 区块时，目标在原版覆盖范围外。客户端确认目标列使用已驻留的 Voxy L1 瓦片；原版视距 14 区块时，同一水块从已加载原版区块产生近景网格，原版方块为 level 0 水源。[三组同机位全图和局部](evidence/coast.png)

| JAR | 原版视距 | Voxy 视距 | 目标水面的实测表现 |
| --- | ---: | ---: | --- |
| 第二阶段 | 3 | 48 | Voxy L1，海面为淡紫色实心面，中间的高楼在水中没有倒影 |
| 第二阶段 | 14 | 48 | Caustica 近景，能见高楼倒影、浅滩和海床。参照只取近景已接管的水域 |
| 第三阶段 | 3 | 48 | Voxy L1，出现同一高楼的倒影，水下能看到海床。海岸与长桥仍是实心表面 |

固定机位使用 `/tp @s -27234.5 126 36316.5 90 13`，时间 6000，晴天。高楼参考坐标 `(-27656, 152, 36316)`。第三阶段在斜向机位 `/tp @s -27252.5 118 36392.5 88 13` 重拍，目标水块仍由 Voxy L1 绘制。对照两图，高楼及其倒影从画面中间移到右侧，近岸岛礁和长桥也呈现不同的透视关系。[正视与斜视](evidence/angles.png)

## 水位、材质和 LOD

测试驱动在客户端查询分段实际驻留、近景覆盖掩码与当前 LOD，并用运行中的生产网格构建入口读取同坐标上表面的世界高度、法线方向和材质标记。

- 水块所在列在 Voxy L0 至 L4 均记录了水源。原版开放水源的表面为 Y=62+8/9。第三阶段分别在 L1（2 格体素）和 L2（4 格体素）下测得水平上表面 **Y=62.8889**，两者均携带水材质与生物群系水色 `#3f76e4`。
- 临岸点 `(-27508, 66, 36316)` 所用的 L2 数据记录为石头，网格上表面 Y=68，材质为实心，颜色 `#707070`。在更贴近水线的 `(-27504, 62, 36316)`，L0 和 L1 记录为水，L2 记录为石头，L2 的实际输出是 Y=64 的石质岸面。这是粗 LOD 会抹平窄水线的实测例子。缺少细层水位时使用对应粗层的可用精度。
- 画面右侧越过已有 Voxy 数据的外缘后，背景可见。移动交接检查使用有记录的海面。岸线、浅滩、桥柱在粗层仍保留体素台阶；建筑和岸边使用原有简化材质。

## 沿东岸飞行与交接

保持原版视距 3、Voxy 视距 48，沿海岸南北方向使用观察者常规移动包前进、停留，再后退。从 `(-27400.5, 94, 36548.5)` 飞到 `(-27400.5, 94, 36338.5)` 后原路返回，镜头始终朝同一水块转动。起点朝向约 177°、俯角 4°，最近处朝向约 150°、俯角 48°。每 3 个客户端刻保留一帧，共 **217 帧，约 32 秒**。[沿岸往返与逐帧来源标注](evidence/shoreline.webp)

以首帧为 0 秒，目标水面在约 2.4 秒由 L2 切入 L1，12.3 秒读到原版近景接管。后退时约 20.9 秒进入 Voxy 交接细分段，25.1 秒回到 L1 瓦片，30.2 秒回到 L2。水位和岸线接续，经过 LOD 或近景边界时未见明显水面裂缝、双层闪烁或整片亮度突跳。浅滩轮廓和途经的岛礁建筑可看出粗细层细节切换。原始连续帧位于 `build/voxy-phase3/shore-flight/screenshots/handoff-*.png`。

## 向岸接近与后退

原版视距 3，Voxy 视距 48，沿东岸视线，从 `(-27204.5, 92, 36316.5)` 向西移动到 `(-27390.5, 92, 36316.5)`，停留后原路后退。朝向固定为 90°，俯角从约 4° 逐渐增至约 50°，让同一片水始终在视野内。测试驱动每个客户端刻移动 1.24 格，每 3 刻采集一帧，连续保留 **109 帧，约 16 秒**。片底标明实际机位 X 与目标水块的覆盖来源。[完整往返动图](evidence/handoff.webp)

前进时采到目标先由 Voxy L2、L1 绘制，之后原版近景接管。后退时依次观察到近景、Voxy 交接细分段、L1 和 L2。整段采样中海面连通，水位与岸线接上，没有观察到明显裂缝、双层闪烁或整片水面突然变亮、变暗。粗层切换时浅滩与地标细节有可见变化。未加字幕的原始连续帧位于 `build/voxy-phase3/new-low/screenshots/handoff-*.png`。

## 第二阶段机位回归

- **近水反射远楼。** `/tp @s -27708.5 66 36744.5 -173.07 39`，时间 6000，原版视距 3，Voxy 视距 48。远楼本体已出画，仍能在近水中辨认绿色竖带与楼体轮廓。移除 Voxy 和 Sodium 后，客户端正常进档，近景水与海床仍由 Caustica 渲染，远楼倒影消失。[第二阶段、第三阶段及无 Voxy 对照](evidence/reflection.png)
- **远楼给近景投影。** `/tp @s -28056.5 113 36272.5 -90 89`，时间 0，同样视距。两阶段在同一近景白色混凝土地面中央均产生宽条阴影。截图中央同一区域的 RGB 通道中位数两次均为 `(89,112,134)`，无 Voxy 时为 `(192,183,181)`。白色地面仅放置在副本中，复现命令为 `/fill -28077 81 36241 -28035 81 36303 minecraft:white_concrete`。[太阳阴影对照](evidence/shadow.png)

## 环境与复现

1. 使用已有 Voxy 数据的 OSHACRA ISLAND 测试副本。沿用第一阶段已升至 26.2 的副本，其中替换了旧 Terralith 生成器，保留原种子、既有区块和 Voxy 数据。测试使用独立实例，关闭 Voxy 采集。
2. Minecraft 26.2，Fabric Loader 0.19.3，Fabric API 0.156.0+26.2，Voxy 0.2.19-beta，Sodium 0.9.1，RTX 4060 Laptop GPU。用观察者模式并固定晴天及游戏时间。FOV 70°，Caustica Vulkan 光追，手动 EV 0，4 spp，最多 4 次反弹，关闭水波和平面云，DLSS-RR 从 427×240 重建至 854×480。平水面让三组的水位及倒影位置可直接比较。
3. 用保留的第二阶段 JAR 进东岸固定机位，原版视距设 3、Voxy 设 48。再将原版视距提高到 14，等海岸和高楼均加载。换第三阶段 JAR，原版视距调回 3，站回固定机位并切到斜向机位。两个观测水面均可按记录的玩家机位与朝向复现。

## 构建与测试

- 可安装 JAR 为 `build/libs/caustica-0.5.jar`。首次构建前保留的第二阶段 JAR 为 `build/voxy-phase3/phase2-caustica-0.5.jar`。
- Gradle 离线构建通过。81 项 JUnit 通过，含水面高度、水下固体面、介质标记和相邻水位台阶的回归。Slang 行为检查 35 项通过，构建中的 SPIR-V 校验通过。
- 旧水体与玻璃脚本仍报告 13 条失败断言，逐条比较与第二阶段一致。天气体积脚本仍报告相同的 60 条失败断言。日志分别位于 `build/voxy-phase3/water.log` 和 `build/voxy-phase3/weather.log`。
